# Свадебное приглашение · Фатхуллоходжа & Шукронахон · 08.12.2026

Интерактивное анимированное приглашение (HTML + CSS + JavaScript, без сборки и зависимостей).

Открыть: `https://muhammadislom99.github.io/wedding-invitation/`

## Сцены

| № | Сцена | Что происходит |
|---|-------|----------------|
| 0 | Открытие | Конверт цвета шампань проявляется из тумана, переливается золотая печать. По нажатию печать рассыпается золотыми искрами, клапан раскрывается, письмо выезжает, и камера «влетает» в него. |
| 1 | Приглашение | Монограмма Ф & Ш, текст «С любовью приглашаем вас разделить с нами самый счастливый день нашей жизни». |
| 2 | Имена | Имена «пишутся» каллиграфией, золотой амперсанд в кольце. |
| 3 | Дата | Цифры 08 • 12 • 2026 поднимаются по одной, по ним пробегает золотой блик, обратный отсчёт до торжества. |
| 4 | Место | Карточка с двойной золотой рамкой и цветами: «Туйхони Зикриддин», кнопка «Открыть на карте». |
| 5 | Финал | Венок с именами, дата, «Будем счастливы видеть вас среди наших дорогих гостей!», подпись. Кнопки «Сначала» и «Поделиться». |

Переход между сценами: открытка перелистывается как страница (3D-поворот с тенью), следующая выплывает из глубины, по сцене проходит световой блик, а лепестки сдувает «ветром» от страницы.

Управление: свайп влево/вверх, колесо мыши / тачпад, стрелки на клавиатуре, кнопки ‹ › и точки внизу.

## Файлы

- `index.html` — разметка сцен и настройки (`window.WEDDING_CONFIG`)
- `style.css` — оформление и анимации
- `app.js` — сцены, переходы, конверт, лепестки и золотые частицы (canvas), параллакс, отсчёт
- `music.js` — фоновая музыка
- `music/` — папка для своего музыкального файла

## Как заменить музыку

По умолчанию играет встроенная мелодия (нежный фортепианный вальс, создаётся прямо в браузере — файл не нужен).

Чтобы поставить свою песню:

1. Положите файл в папку `music/`, например `music/wedding.mp3`.
2. В `index.html` в блоке `WEDDING_CONFIG` укажите путь:
   ```js
   musicSrc: 'music/wedding.mp3',
   ```

Музыка включается только после действия гостя: при открытии конверта или по кнопке с нотой (справа внизу).

## Как указать точную точку на карте

В `index.html` замените `mapUrl` на ссылку из Яндекс Карт или Google Maps (кнопка «Поделиться» → «Скопировать ссылку»):

```js
mapUrl: 'https://yandex.uz/maps/-/XXXXXX',
```

## Обратный отсчёт

`dateISO: '2026-12-08T00:00:00'` — можно указать точное время начала, например `'2026-12-08T18:00:00'`.
